# Tooné

Single-page website for **Tooné**, a small studio making personalized cartoon portraits, UNO card decks and keychains (site in Romanian).

- Price list, portfolio gallery and order/collaboration forms (the forms generate a message to paste into an Instagram DM, no backend)
- Live color palette picker, scroll animations and particle effects
- Plain HTML, CSS and JS in one `index.html`, no build step. Just open it in a browser.
